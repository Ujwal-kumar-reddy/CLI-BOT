# CLI-BOT: High-Fidelity AI Website Cloner

An intelligent AI Agent built with **Node.js** that uses the **ReAct (Reasoning + Acting)** pattern to clone web dashboards with pixel-perfect accuracy. This project demonstrates autonomous agent logic and UI/UX engineering.

## 🚀 Features
- **Autonomous Reasoning**: Uses a `THINK -> TOOL -> OBSERVE` loop to plan and execute UI tasks.
- **High-Fidelity UI**: Generates responsive layouts using **Tailwind CSS** and **Grid-based architectures**.
- **Real-time Feedback**: Monitors tool outputs and adjusts logic based on system observations.
- **Modern Tech Stack**: Powered by **Groq (Llama-3.3-70b)** for lightning-fast inference.

## 🛠️ Tech Stack
- **Runtime**: Node.js
- **LLM**: Llama-3.3-70b (via Groq Cloud)
- **Styling**: Tailwind CSS CDN
- **Communication**: OpenAI SDK
